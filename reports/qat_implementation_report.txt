3. **ExponentialDecay Learning Rate Scheduler:**
   - Replaced ReduceLROnPlateau with proactive ExponentialDecay scheduler
   - Implementation: decay_rate=0.9, decay_steps=10000, staircase=True
   - Benefits: Predictable learning rate reduction, stable training progression
   - FPGA Optimization: Consistent training for hardware deployment

4. **Enhanced Data Augmentation Pipeline:**
   - Added RandomCrop (p=1.0) for consistent input size
   - Added RandomGamma (p=0.2) for lighting variations
   - Added ImageNet normalization with standard preprocessing
   - Benefits: Improved robustness and generalization

5. **Layer-wise Quantization with Stochastic Rounding:**
   - BatchNorm layers: 8-bit with 1 integer bit and stochastic rounding
   - Activation layers: 8-bit with 6 integer bits and stochastic rounding
   - Convolutional layers: Enhanced 8-bit configuration with stochastic rounding
   - Benefits: Improved training stability and reduced quantization errors

6. **FPGA-Optimized Architecture:**
   - Depthwise separable convolutions in encoder blocks 2 & 3 and mirrored in decoder
   - Symmetric decoder mirrors encoder: conv + SE attention at dec3 and dec2; no attention at dec1
   - Bridge refined with two convs + SE attention; optional training-only dropout removed for export
   - Feature Pyramid Fusion combines multi-scale features using 1x1 convs and fixed resizing
   - Bilinear upsampling instead of transposed convolutions; 1x1 convolutions for efficient channel adjustments
   - Benefits: Reduced computational complexity and memory usage

7. **Dilated Convolutions:**
   - Added dilated convolutions (dilation_rate=2) in strategic locations
   - Bridge block for better context understanding and larger receptive fields
   - Encoder block 3 for enhanced feature extraction
   - Feature pyramid fusion for improved multi-scale feature understanding
   - Benefits: Better context understanding and boundary detection

Data-Driven Quantization Optimization
------------------------------------

### Weight Analysis Findings
Comprehensive analysis of the trained model (epoch 70) revealed precise quantization requirements:

**Layer Categories & Actual Weight Ranges:**
- **Input/Output layers (26 layers)**: Range [-6.52, 1.82] → **4 integer bits required**
- **Encoder/Decoder layers (56 layers)**: Range [-2.92, 6.66] → **4 integer bits required**  
- **Bridge/Critical layers (34 layers)**: Range [-2.13, 2.55] → **3 integer bits required**

### Enhanced Quantization Configuration

**Previous Generic Configuration:**
```python
# Old settings (inefficient bit allocation)
quantized_bits_8_config:  8 bits (4 int, 4 frac) 
quantized_bits_16_config: 16 bits (8 int, 8 frac) # Wasted integer bits
quantized_bits_32_config: 32 bits (8 int, 24 frac) # Wasted integer bits
```

**New Enhanced Configuration:**
```python
# Optimized based on actual weight analysis with latest enhancements
quantized_bits_8_config:  8 bits (4 int, 4 frac)    # Optimal for input/output
quantized_bits_16_config: 16 bits (4 int, 12 frac)  # 32x better fractional precision
quantized_bits_32_config: 32 bits (3 int, 29 frac)  # Maximum fractional precision

# NEW: Layer-wise quantization configurations
quantized_bits_batchnorm_config: 8 bits (1 int, 7 frac) with stochastic rounding
quantized_bits_activation_config: 8 bits (6 int, 2 frac) with stochastic rounding
```

### Quantization Improvements

1. **8-bit Configuration (Input/Output):**
   - **Maintained**: 4 integer bits (sufficient for range [-6.52, 1.82])
   - **Range**: [-16, 15.9375] with 0.0625 precision
   - **Covers**: All input/output layer weights with adequate headroom

2. **16-bit Configuration (Encoder/Decoder):**
   - **Optimized**: 4 integer bits (reduced from 8, saves 4 bits)
   - **Improved**: 12 fractional bits (increased from 8, 32x better precision)
   - **Range**: [-16, 15.999756] with 0.000244 precision
   - **Efficiency**: Optimal for encoder/decoder layers

3. **32-bit Configuration (Bridge/Critical):**
   - **Optimized**: 3 integer bits (reduced from 8, saves 5 bits)
   - **Maximized**: 29 fractional bits (increased from 24, 32x better precision)
   - **Range**: [-8, 7.999999999] with 1.86e-09 precision
   - **Perfect**: For bridge layers requiring maximum precision

4. **NEW: Layer-wise Configurations:**
   - **BatchNorm**: 8-bit with 1 integer bit and stochastic rounding for stability
   - **Activations**: 8-bit with 6 integer bits and stochastic rounding for better training
   - **Benefits**: Improved training stability and reduced quantization errors
