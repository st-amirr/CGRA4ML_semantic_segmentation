OVERVIEW
--------
CGRA4ML is a Python library for building, training, and implementing deep ML models 
(ResNet CNNs, Autoencoders, Transformers) on FPGAs and custom ASICs. It provides a 
highly flexible, high-performance accelerator system with a simple Python API.

KEY FEATURES
------------
✅ Statically & dynamically reconfigurable AXI-Stream DNN engine
✅ Open source framework with customizable processing elements
✅ Support for custom data types and architectures
✅ System-on-Chip (SoC) integration capabilities
✅ C firmware generation for accelerator control
✅ FPGA and ASIC implementation workflows

COMPATIBILITY ANALYSIS
======================

1. MODEL ARCHITECTURE COMPATIBILITY
-----------------------------------

✅ Supported Model Types:
   - ResNet CNNs (similar to LMIINet's encoder-decoder structure)
   - Deep Neural Networks with multiple layers
   - Quantized models (QAT support)

✅ Layer Compatibility:
   - Conv2D layers (encoder path)
   - DepthwiseConv2D layers (MobileNet-style)
   - BatchNormalization layers
   - Activation layers (ReLU, etc.)
   - UpSampling2D layers (decoder path)
   - Dense layers (classification head)

❌ Potential Issues:

======================

✅ Better for Deep Networks:
   - Solves HLS4ML's limitation with deeper networks
   - Single reconfigurable engine vs. one engine per layer
   - More efficient resource utilization

✅ Higher Performance:
   - Optimized dataflow architecture
   - Better memory management
   - Reduced resource overhead

✅ More Flexible:
   - Customizable processing elements
   - Adaptable to specific requirements

✅ Better Integration:
