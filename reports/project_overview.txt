Project Overview and Objectives - UPDATED August 8, 2025
============================================================

1. **Primary Goal:**
   - Train a semantic segmentation model for FPGA implementation using hls4ml and QKeras with Quantization-Aware Training (QAT).
   - Maximize segmentation accuracy while ensuring the model fits and runs efficiently on high-end FPGAs (e.g., Xilinx VCU118).

2. **Technical Context:**
   - **Training Strategy:** Two-phase approach following hls4ml best practices:
     * Phase 1: Float32 baseline training for optimal convergence (50-100 epochs)
     * Phase 2: QAT fine-tuning using trained float32 weights (15-30 epochs)
   - **Frameworks:** TensorFlow/Keras for model definition and training; QKeras for quantization; hls4ml for FPGA conversion.
   - **Enhanced Quantization:** Data-driven multi-precision quantization based on actual trained model analysis with latest enhancements:
     * 8-bit: Input/output layers - 4 integer bits, 4 fractional bits (range: [-16, 15.9375])
     * 16-bit: Encoder/decoder layers - 4 integer bits, 12 fractional bits (range: [-16, 15.999756])
     * 32-bit: Bridge/critical layers - 3 integer bits, 29 fractional bits (range: [-8, 7.999999999])
     * NEW: Layer-wise quantization with stochastic rounding for enhanced QAT performance
    - **Model Architecture:**
      - U-Net encoder-decoder with skip connections, attention blocks, and optimized multi-precision quantization
      - NEW: Symmetric decoder mirrors encoder: conv + SE attention in mid/deep stages (dec3/dec2), no attention at shallow stage (dec1)
     - FPGA-compatible design (no MaxPooling2D, optimized for hls4ml synthesis)
     - Input size: 512x1024x3, output: 512x1024x20 (Cityscapes: 19 trainIds + 1 void)
     - Configurable dropout layers (automatically removed for HLS4ML export)
      - NEW: Depthwise separable convolutions in encoder/decoder blocks for FPGA efficiency
      - NEW: Feature Pyramid Fusion to combine multi-scale features from skips and bridge
      - NEW: Bilinear upsampling instead of transposed convolutions for hardware compatibility
   - **Data Pipeline:**
     - Efficient `CityscapesDataGenerator` with enhanced Albumentations augmentation
     - Configurable dataset subset ratios for testing (0.1-1.0)
     - Optimized batch processing with prefetch buffer
     - NEW: Enhanced augmentation including RandomCrop, RandomGamma, and ImageNet normalization
   - **Training Environment:**
     - Docker container with GPU support and comprehensive dependency management
     - GPU utilization optimizations (mixed precision, memory growth management)
     - TensorBoard integration for real-time monitoring with comprehensive metrics
     - NEW: ExponentialDecay learning rate scheduler for stable training progression
   - **Monitoring & Visualization:**
     - Real-time TensorBoard logging with organized metric groups
     - Custom prediction visualizations with Cityscapes color coding
     - Learning rate tracking and IoU metrics per class
     - Weight histogram analysis and distribution monitoring
     - Automatic checkpoint resumption and progress persistence
