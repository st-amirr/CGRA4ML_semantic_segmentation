LATEST ENHANCEMENTS SUMMARY (August 8, 2025)
-------------------------------------------
The training pipeline has been significantly enhanced with the following improvements:

1. **ExponentialDecay Learning Rate Scheduler**: Replaced ReduceLROnPlateau with proactive ExponentialDecay scheduler (decay_rate=0.9, decay_steps=10000, staircase=True) for stable training progression.

2. **Enhanced Data Augmentation**: Added RandomCrop (p=1.0), RandomGamma (p=0.2), and ImageNet normalization for improved robustness and generalization.

3. **Layer-wise Quantization with Stochastic Rounding**: Implemented different quantization precision for different layer types:
   - BatchNorm layers: 8-bit with 1 integer bit and stochastic rounding
   - Activation layers: 8-bit with 6 integer bits and stochastic rounding
   - Convolutional layers: Enhanced 8-bit configuration with stochastic rounding

4. **FPGA-Optimized Architecture**: 
   - Depthwise separable convolutions in encoder blocks 2 & 3 and mirrored in decoder
   - Symmetric decoder mirrors encoder: conv + SE attention at dec3/dec2; no attention at dec1
   - Bridge refined with two convs + SE attention; training-only dropout removed on export
   - Feature Pyramid Fusion for multi-scale aggregation using 1x1 convs and fixed resizing
   - Bilinear upsampling instead of transposed convolutions; 1x1 convolutions for efficient channel adjustments

5. **Dilated Convolutions**: Added dilated convolutions (dilation_rate=2) in strategic locations:
   - Bridge block for better context understanding
   - Encoder block 3 for enhanced feature extraction
   - Feature pyramid fusion for improved multi-scale feature understanding

These enhancements provide superior training stability, improved QAT performance, better FPGA deployment efficiency, and enhanced context understanding through larger receptive fields.

3.5 FPGA-Optimized Architecture Enhancements (LATEST IMPROVEMENT)
**REVOLUTIONARY: Depthwise Separable Convolutions and Hardware Optimizations**

**New Depthwise Separable Convolution Block:**
```python
def depthwise_separable_conv_block(x, filters, use_quantization=False, name='depthwise_sep'):
    # Depthwise convolution
    if use_quantization:
        x = QDepthwiseConv2D(kernel_size=3, padding='same', use_bias=False, name=f'{name}_depthwise')(x)
        x = QBatchNormalization(
            gamma_quantizer=quantized_bits(**quantized_bits_batchnorm_config),
            beta_quantizer=quantized_bits(**quantized_bits_batchnorm_config),
            name=f'{name}_depthwise_bn')(x)
    else:
        x = DepthwiseConv2D(kernel_size=3, padding='same', use_bias=False, name=f'{name}_depthwise')(x)
        x = BatchNormalization(name=f'{name}_depthwise_bn')(x)
    
    # Pointwise convolution
    if use_quantization:
        x = QConv2D(filters, kernel_size=1, padding='same', use_bias=False, name=f'{name}_pointwise')(x)
        x = QBatchNormalization(
            gamma_quantizer=quantized_bits(**quantized_bits_batchnorm_config),
            beta_quantizer=quantized_bits(**quantized_bits_batchnorm_config),
            name=f'{name}_pointwise_bn')(x)
    else:
        x = Conv2D(filters, kernel_size=1, padding='same', use_bias=False, name=f'{name}_pointwise')(x)
        x = BatchNormalization(name=f'{name}_pointwise_bn')(x)
    
    return x
```

**Architecture Integration:**
- **Encoder Blocks 2 & 3**: Replaced `conv_block` with `depthwise_separable_conv_block`
- **Benefits**: Reduced computational complexity and memory usage
- **FPGA Efficiency**: More hardware-friendly operations for deployment

**Optimized Feature Pyramid Fusion:**
- **Lightweight Convolutions**: 1x1 kernels for channel adjustment
- **Bilinear Resizing**: Hardware-friendly upsampling method
- **Reduced Channels**: Efficient skip connection processing

**Decoder Path Optimization:**
- **Bilinear Upsampling**: `UpSampling2D` instead of transposed convolutions
- **Hardware Compatibility**: Avoids complex operations not well-supported on FPGA
